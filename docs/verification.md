테스트의 MockMvc는 실제 Spring Security 필터와 서비스·JPA를 함께 실행합니다. 화면 검사는 실제 서버의 로그인 폼을 제출해 세션을 얻은 후 현황·등록·상세·검색·권한을 확인했습니다. 화면 검사는 읽기와 로그인만 수행합니다.

## 선택한 경계

- 사업 완료와 연결 업무의 완료 여부를 서비스에서 검사합니다.
- `@Version`으로 같은 레코드의 동시 갱신을 검출합니다. 서로 다른 레코드에 걸친 대규모 동시 업무 처리의 격리 수준·락 정책은 별도 검증 대상입니다.
- 이력은 애플리케이션에서 추가만 하지만 DB 관리자에 의한 변경 방지나 서명·외부 감사 보관까지 구현하지 않았습니다.
- 화면 테스트가 기본 시연 데이터에 의존하므로 사용자가 데이터를 편집했다면 별도 DB 경로로 실행한 뒤 검사할 수 있습니다.

```powershell
$env:APP_DB_URL='jdbc:h2:file:./data/browser-demo;DB_CLOSE_ON_EXIT=FALSE'
.\mvnw.cmd spring-boot:run
```

실행 스크린샷은 `docs/images/`에 있습니다. 이 문서의 결과는 로컬 실행 결과이며 실제 서비스 운영 실적을 의미하지 않습니다.
